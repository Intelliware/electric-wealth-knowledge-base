# Cross-cutting: Localization (i18n)

> **Owning repo:** `web` · **Primary pointer:** [`source-docs/electric-wealth-web/web-app-consumer/08-localization-integration.md`](../../source-docs/electric-wealth-web/web-app-consumer/08-localization-integration.md)

Two locales, `en-CA` and `fr-CA`. The web app translates UI text with i18next and sends `Accept-Language`; the API localises catalogue text from `_en` / `_fr` columns (education, security questions, quick-link labels, welcome notification). Components: `web-i18n-and-formatting`, `api-education`, `api-dashboard`, `api-registration`, `db-learning-centre`.
